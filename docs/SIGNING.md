# Установка и пере-подпись BookTrans (Windows 11 + iPhone, бесплатный Apple ID)

Приложение собирается в GitHub Actions как **неподписанный** `BookTrans.ipa`.
Подпись делает компьютер один раз, дальше — сам телефон через SideStore.

Источники (проверены 2026-09-11):

- <https://docs.sidestore.io/docs/installation/prerequisites>
- <https://docs.sidestore.io/docs/troubleshooting/common-issues>
- <https://github.com/nab138/iloader>
- <https://docs.sidestore.io/docs/release-notes>

## Ограничения бесплатного аккаунта

|Ограничение|Значение|
|---|---|
|Приложений на устройстве|3 (включая сам SideStore)|
|Новых App ID в неделю|10|
|Срок жизни сертификата и приложения|7 дней|
|Платный Apple Developer|не нужен ни на одном шаге|

Из трёх приложений одно занимает SideStore, одно — BookTrans, одно остаётся в
запасе. Туннель (`LocalDevVPN`) приложением из этого лимита **не** считается,
потому что ставится из App Store.

## Что понадобится

1. **iTunes с сайта Apple**, не из Microsoft Store:
   <https://www.apple.com/itunes/download/win64>. Он ставит usbmuxd-драйверы,
   без которых iloader не увидит телефон. AltServer/Win10-версии из Store
   не подходят.
2. **iloader** для Windows: <https://github.com/nab138/iloader/releases> —
   `iloader-windows-x64.msi` (или `.exe`). Версия из проверенных — v2.3.3.
3. **LocalDevVPN** на iPhone: App Store, id `6755608044`
   (<https://apps.apple.com/ru/app/localdevvpn/id6755608044>).
   StosVPN больше не подходит: он удалён из App Store, а документация SideStore
   прямо просит перейти на LocalDevVPN.
4. iPhone с iOS 26.5, кабель, доверие компьютеру.

Это значит: **шаг «Install SideStore» в iloader делает пользователь** — вход в Apple ID
и 2FA автоматизировать нельзя, и пароль не должен покидать вас.

## Первая установка

1. Установите iTunes и iloader на Windows.
2. Подключите iPhone кабелем, на телефоне нажмите «Доверять».
3. Запустите iloader. Он должен увидеть устройство.
4. Выберите **Install SideStore** и войдите обычным (бесплатным) Apple ID.
   iloader подписывает SideStore этим аккаунтом и ставит его на телефон.
5. На iPhone: **Настройки → Основные → VPN и управление устройством** →
   доверьте профилю разработчика.
6. **Настройки → Конфиденциальность и безопасность → Режим разработчика** →
   включите и перезагрузите телефон. Пункт появляется после первой установки
   сайдлоада.
7. Установите **LocalDevVPN** из App Store, откройте и подключитесь
   («Разрешить VPN-конфигурацию» → код-пароль). Туннель должен быть включён
   всегда, когда SideStore ставит, обновляет или продлевает приложения.
8. Откройте SideStore, войдите тем же Apple ID и разрешите продление в фоне.
9. Скачайте `BookTrans.ipa` из артефактов GitHub Actions:
   репозиторий → **Actions** → последний зелёный запуск → раздел **Artifacts** →
   `BookTrans-ipa` (хранится 14 дней).
10. В iloader: **Import IPA** → выберите `BookTrans.ipa` → установите на
    подключённый телефон. Подпись — тем же бесплатным Apple ID.
11. На телефоне доверьте новому профилю разработчика, если iOS попросит.

Проверка: BookTrans запускается, тема тёмная, в «Файлах» видна папка **BookTrans**.

## Продление каждые 7 дней

SideStore продлевает приложения **на самом телефоне**, пока он жив:

1. Включите Wi-Fi и **LocalDevVPN**.
2. Откройте SideStore → **Refresh All** (или дайте ему сделать это в фоне).

Отсчёт у SideStore свой, и он должен продлеваться не реже раза в 7 дней. Если
просрочить и SideStore, и BookTrans, они перестанут запускаться — тогда снова
подключите телефон к ПК и повторите установку через iloader.

**Данные приложения при этом сохраняются**: bundle id не меняется
(`com.gennadiy.booktrans`), поэтому библиотека, переводы и глоссарий остаются на
месте. Переустановка без удаления — обычный путь обновления.

## Обновление на новую сборку

1. Дождитесь зелёного запуска CI на нужном коммите.
2. Скачайте свежий `BookTrans.ipa`.
3. Включите LocalDevVPN, откройте SideStore → **Import** (или iloader по кабелю) →
   установите поверх. Данные сохраняются.

## Если что-то не работает

|Симптом|Что делать|
|---|---|
|iloader не видит телефон|iTunes с сайта Apple не установлен (нужны драйверы Apple Mobile Device); переподключите кабель, проверьте «Доверять»|
|SideStore не устанавливает и не продлевает|LocalDevVPN выключен, либо нет Wi-Fi. Ошибка SideStore 1414 — это как раз про это|
|`minimuxer error 27` на iOS 26.4+|Документация SideStore советует ночную сборку SideStore для iOS 26.4 и новее|
|`This app is not available in your region` для туннеля|Туннель ставится из App Store; если в вашем регионе его нет — заведите второй Apple ID с подходящим регионом только ради него (сайдлоад можно оставить на основном)|
|«Не удалось проверить подпись»|Сертификат истёк (>7 дней без refresh). Подключите телефон к ПК и переустановите через iloader — данные сохранятся|
|Закончились App ID (10 в неделю)|Подождите неделю; лимит общий на устройство, смена Apple ID не помогает|

## Почему IPA неподписанный

`CODE_SIGNING_ALLOWED=NO` в CI: подпись выполняется на устройстве/iloader-ом
сертификатом вашего Apple ID. Поэтому в репозитории нет ни профилей, ни ключей, а
артефакт можно безопасно хранить публично.
